One funny single-line excuse a developer gives when code breaks in
production, written to `/output/entry.txt` by `main.py`.

## The entry

> The code passed every test. Unfortunately, production wasn't one of them.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

No dependencies, no network, no secrets. The program writes exactly
one line (73 characters) to `/output/entry.txt`.
